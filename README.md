# MachaHub: first look

An installable web app of the MachaHub prototype: every screen, using sample data only. There's no backend and no real accounts.

**Try it:** https://chvrolledout.github.io/machahub-app/

- **Android:** open it in Chrome → tap "Install" (or ⋮ → Add to Home screen)
- **iPhone:** open it in Safari → tap Share → "Add to Home Screen"

This repo is generated. Don't edit it by hand: it's built by `python3 prototype/build.py` in the main MachaHub repo (`prototype/site/`).
